# Processed Data

This folder contains small standardized samples used by the Streamlit demo.

## Included file

`lade_p_standardized_sample.csv`

This is a standardized 10,000-record sample derived from the public LaDe-P dataset.
It is mapped into the LogiDelay standard schema and used as the built-in public
benchmark sample in the Streamlit app.

The full raw LaDe-P dataset is not committed to this repository.
